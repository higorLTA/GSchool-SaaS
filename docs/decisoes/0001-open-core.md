# 0001. Adocao do modelo open core

- Status: Aceito
- Data: 2026-11-18

## Contexto

O projeto precisa servir como portfolio tecnico e, ao mesmo tempo, sustentar um produto comercial. E importante separar uma base aberta reutilizavel de recursos que tenham valor exclusivo para clientes.

## Decisao

O nucleo do projeto sera distribuido sob AGPL-3.0. Os modulos comerciais, contidos na pasta `ee/`, serao proprietarios e somente poderao ser usados mediante licenca comercial do autor.

## Consequencias

- Contribuicoes ao nucleo devem respeitar o licenciamento AGPL.
- Usuarios de rede precisam receber o codigo-fonte correspondente das modificacoes cobertas pela licenca.
- Modulos proprietarios permanecem separados e podem ser licenciados para clientes.
- Documentacao, limites de licenca e estrutura do repositorio ficam claros para contribuidores e entrevistas profissionais.
